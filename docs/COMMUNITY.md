## Preview versus the released model

The June X launch post identifies **1.5 Preview**. The [official release article](https://x.ai/news/grok-imagine-video-1-5) describes the generally available `grok-imagine-video-1.5` and credits David Thompson / Heavy Pulp in **Behind the Scenes — Odyssey**. Keep these labels separate. X trend summaries used inconsistent trailer names during discovery; this library follows the official article's title instead.
