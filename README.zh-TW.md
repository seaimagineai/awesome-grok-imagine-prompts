## 快速使用原則

- 1–15 秒的短片只安排一個主要動作與一個清楚的運鏡。
- 圖生影片要先鎖定人物、產品形狀、材質、光線與構圖，再描述動態。
- 對白請保留目標語言原句，並指定語氣、停頓、地區口音與混音優先順序。
- 參考圖各自只負責一項內容：身分、服裝、產品、場景或聲音。
- 最後一秒保持穩定，方便剪輯或繼續延長。

## 共用多語言測試：陶燈工坊

**模式：**圖生影片 · **輸出：**8 秒 · 16:9 · 720p

```text
保留輸入圖片中的虛構成年工藝師、臉部、手部、靛藍圍裙、原創穿孔陶燈、木製工具、工坊層架、
構圖與溫暖側光。陶燈的輪廓、開孔數量與排列完全不變。

0–3 秒：鏡頭緩慢向前推進約 5 公分。工藝師左手穩住燈座，右手用現有的軟刷沿陶面刷過一次；
細微陶土粉塵在側光中自然落下。3–6 秒：工藝師轉動既有的調光旋鈕一次，暖光逐漸從原有小孔
透出，然後用自然的繁體中文說：「這些小孔，會讓光變得更柔和。」6–8 秒：工藝師放下刷子，
看向陶燈，鏡頭停止，最後一秒保持穩定。

聲音：刷毛接觸陶面的聲音、旋鈕輕響、安靜工坊環境與清楚近距離人聲；不要音樂與字幕。

連續性鎖定：人物身分、手部、圍裙、陶燈形狀與孔位、工具、層架、光線方向全部不變。
避免多餘手指、燈具重新設計、孔洞增加、臉部漂移、假文字、Logo、鏡頭切換或過度光暈。
```
